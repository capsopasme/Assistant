# 助手（Assistant）

给 **小米 13 · HyperOS 3（国行，KernelSU root）** 写的轻量手机助手：长按电源键唤起，用文字或
[离线语音输入（Audio Input）](https://github.com/capsopasme/audio_input) 说出指令。常用指令在本机直接执行（不联网、瞬间完成），
其余交给 DeepSeek / 智谱 GLM / Gemini 中你选定的一个，通过工具调用操作手机或回答问题。没有语音播报，没有常驻服务。

## 安装与配置

1. 安装 [Releases](https://github.com/capsopasme/Assistant/releases) 里的 APK。
2. 在 **KernelSU 管理器**里给「助手」开启超级用户（KernelSU 不会弹窗询问）。
3. 打开「助手」→ **一键配置**。它会：
   - 把本应用设为默认数字助理（`cmd role add-role-holder`）；
   - 让长按电源键唤起数字助理（`long_press_power_key=launch_google_search`），而不是小爱；
   - 把语音识别服务指向小米自带引擎，避免重启后被系统重置为小爱；
   - 允许「后台弹出界面」和「锁屏显示」（从面板打开其他应用需要）；
   - 授予通讯录和拨号权限（按姓名打电话）；
   - 关闭助理的读屏 / 截屏（每次唤起都不会截取屏幕）；
   - 授予切换输入法（`WRITE_SECURE_SETTINGS`）、修改系统设置、自启动权限。
4. 在「大模型」里选服务并填写 API Key（加密保存在本机，不进 APK、不备份）。
5. 长按电源键试试。没反应就重启一次手机。

## 能做什么

| 类别 | 例子 | 本地直接处理 |
|---|---|---|
| 打开应用 | 打开微信 / 打开B站 / 打开留声机 | ✓（标签、拼音、别名模糊匹配） |
| 倒计时 | 倒计时十分钟 / 一个半小时后提醒我喝水 | ✓ |
| 闹钟 | 明早七点叫我 / 工作日 6 点 50 的闹钟 / 查看闹钟 | ✓ |
| 打电话 | 给妈妈打电话 / 打给 138… | ✓（联系人同音容错，有歧义会列出候选，不乱拨） |
| 导航 | 导航到西湖 / 步行去火车站 / 回家 | ✓（CoMaps 或高德，设置里选） |
| 音乐 | 播放周杰伦的晴天 / 随机播放 / 下一首 / 暂停 | ✓（留声机 Gramophone） |
| 系统开关 | 打开蓝牙 / 关闭 WLAN / 飞行模式 / 移动数据 / 深色模式 / 护眼模式 / 手电筒 / 勿扰 / 定位 / 自动旋转 / NFC | ✓（root） |
| 音量亮度 | 音量调到 30 / 声音大一点 / 屏幕暗一点 / 亮度 40% | ✓ |
| 网页搜索 | 搜索 xxx | ✓ |
| 其他 | 问问题、多步指令（"打开蓝牙然后放首歌"）、不常见说法 | 交给大模型 |

开关执行后会读回系统真实状态再报告（例如蓝牙真的开了才说"已打开"）。

## 使用

- 唤起后自动切到 Audio Input 开始听，整句上屏约 1 秒后自动发送；关闭面板时切回原来的键盘（异常退出也会在下次恢复）。
- 左下角按钮在语音 / 键盘之间切换。点面板外、按返回或打开了别的应用，面板就关闭。
- 执行类指令完成后面板自动收起；回答类结果会停留，可以接着追问（5 分钟内保留上下文）。

## 稳定与省电

- **没有前台服务、没有唤醒锁、没有轮询。** 系统绑定的数字助理服务平时什么都不做；被唤起时把面板画在它自己的窗口里，关闭后释放。
- root shell 按需开启，一次指令里的多条命令共用一个会话，空闲 20 秒自动关闭。
- 网络请求用系统 `HttpURLConnection`，不引入额外库；关闭面板立即取消请求。
- 应用列表只在安装/卸载后重建（`PackageManager.getChangedPackages`），联系人只在打电话时读取。
- 各家模型对"关闭思考"参数支持不一，请求被拒时自动去掉参数重试一次并记住，不会因换模型而不可用。

## HyperOS 相关的坑

- 国行 HyperOS 的长按电源键默认直接唤起小爱，只有 `long_press_power_key=launch_google_search` 时才交给默认数字助理。
- HyperOS 开机时会重新初始化语音助理，若识别服务不可用会改回小爱：因此把识别服务指向 `com.xiaomi.mibrain.speech`，并在开机后（以及助理服务被绑定时）检查一遍，被改掉就自动恢复。开机恢复依赖「自启动」，一键配置会尝试授予，失败时设置页有入口。
- 从后台启动 Activity 在 HyperOS 上靠不住：前台是别的应用时，面板 Activity 会被压住，等助手自己回到前台才弹出来。所以面板直接画在数字助理会话的系统窗口里（和 Gemini / Google 助理的浮层同一机制），盖在任何应用上，不需要启动 Activity。
- 从面板打开其他应用仍受「后台弹出界面」（MIUI app-op 10021）约束，一键配置会用 root 允许它（同时允许「锁屏显示」10020）。设置页的「最近一次长按电源键」会显示是否收到、面板是否显示。
- 戴耳机时调高音量可能被系统的安全音量限制，结果里会如实说明。
- 深色模式同时设置 AOSP 夜间模式和 HyperOS 自己的 `dark_mode_enable`；护眼模式使用 `screen_paper_mode_enabled`。

## 构建

```sh
./gradlew :app:testDebugUnitTest :app:assembleRelease
```

CI（GitHub Actions）在每次推送时跑单元测试并构建 APK。发版：Actions → Build → Run workflow 填 `release_tag`（如 `v1.0.0`），或推送 `v*` 标签。
签名用仓库 secrets 里的 keystore，按内容自动识别（secret 叫什么名字都行），没有正式签名时拒绝发版。
